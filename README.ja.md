# 家計簿

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

**現在のバージョン：0.2.0 · 初回公開リリース**

家計簿は、個人や家庭のお金を管理するオープンソースのローカル優先アプリです。収入・支出・振替の記録、口座やクレジットカードの管理、予算・残高・期間レポートの確認に使えます。デスクトップ版は Python、Tkinter、SQLite で動作し、台帳は初期状態では自分の PC に保存されます。銀行とは接続せず、支払いや返済を実行することもありません。

「昨日の昼食、850 JPY、現金で支払い」のような自然な文章で記帳したり、レシート画像を添付したりできます。自然言語入力は任意機能で、利用者が設定したローカル Ollama または OpenAI 互換モデルが必要です。保存前に候補内容を確認してください。必要な情報が不足している場合、アプリが追加で質問します。

## 主な機能

- 収入、支出、口座間振替、残高確認を記録（JPY と CNY は別々に管理）
- 銀行、現金、ウォレット、プリペイド、交通系 IC、ポイント、クレジットカード口座を管理
- 日付で明細を検索し、誤った取引を手動で編集・削除
- 貸借対照表、損益計算書、カテゴリ別支出、予算の進捗を確認（標準の会計期間は毎月15日から翌月14日）
- 定期取引、利用枠スナップショット、ローカルの返済予定を管理（カード債務は台帳上の推定値であり、銀行のリアルタイム情報ではありません）
- 固定資産を登録し、月次減価償却後の帳簿価額を表示
- ローカルバックアップを作成。デスクトップ版は GitHub または Gitee の非公開リポジトリと同期可能
- 任意で Web/PWA クライアントを利用（自然言語入力、クラウド同期、Web 公開にはそれぞれ設定が必要）

## Windows デスクトップ版のインストールと起動

Windows、Git（または GitHub ZIP のダウンロード）、および Tkinter を含む **Python 3.11 以降**が必要です。

PowerShell で次のコマンドを実行します。

```powershell
git clone https://github.com/Astar915/household-bookkeeping-basic.git
cd household-bookkeeping-basic
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m bookkeeping.cli init
.\.venv\Scripts\pythonw.exe -m bookkeeping.gui
```

GitHub の **Download ZIP** を使う場合は、ZIP を展開し、展開先のプロジェクトフォルダーで PowerShell を開いてください。その場合は `git clone` と `cd household-bookkeeping-basic` の2行を実行しません。

初期化すると、空の台帳 `data/household_bookkeeping.sqlite3` が作成されます。画面を試す場合は、新しい空の台帳に限り、通常の初期化の**代わりに** `python -m bookkeeping.cli init --seed-demo` を実行できます。架空のデモデータが登録されます。既存の台帳に対してデモ初期化を実行しないでください。

依存関係をインストールした後は、プロジェクトフォルダー内の `launch-bookkeeping.vbs` をダブルクリックしてデスクトップ画面を起動することもできます。

## 初めて使うとき

1. **口座と開始残高を登録します。** 「資産」から口座を管理します。現金、銀行、ウォレット、プリペイド、交通系 IC などは「その他 → 現金管理」で管理できます。クレジットカードは「その他 → クレジットカード管理」で別に登録し、確認できる利用枠スナップショットを入力します。ご自身の口座と実際の残高だけを登録してください。
2. **表示言語と Agent を設定します。** 設定から表示言語を変更できます。自然言語入力を使う場合は「設定 → API サービス」に Ollama または OpenAI 互換サービスを追加し、「Agent と Skill の設定」で家計簿 Agent に割り当てます。ローカル Ollama を使う場合、リクエストは PC 内で処理されます。リモートサービスには送信した文章や画像が送られます。
3. **取引を記録します。** 「記録 → 家計簿」を開き、日付、用途、金額、通貨、口座を文章で伝えます。追加質問が表示されたら回答してください。候補内容を確認して確定すると、ローカル台帳に保存されます。画像認識はレシートの読み取りを補助しますが、金額や実際の支払口座は必ず確認してください。
4. **台帳を確認します。** 取引明細の画面で検索、絞り込み、修正ができます。「その他 → 家計財務レポート」で貸借対照表と損益計算書を確認し、ホーム画面で予算の進捗を確認できます。現金残高やカード利用枠は、実際の記録に基づいて入力してください。アプリは銀行情報を取得しません。
5. **バックアップを作成します。** 「設定 → 台帳とバックアップ」でローカルバックアップを作成します。複数端末で同期する場合は GitHub または Gitee を自分で接続し、事前に同期範囲と復元方法を説明書で確認してください。

モデルサービスが未設定でも、デスクトップアプリを起動してローカル台帳を閲覧・管理できます。ただし、アプリ内の自然言語記帳にはモデルサービスの設定が必要です。モデルを使わない場合は、CLI の `income`、`expense`、`transfer` コマンドで直接記帳できます。各コマンドに `--help` を付けると必須項目を確認できます。

## 任意機能：Web/PWA クライアント

プロジェクトフォルダーで Web 用依存関係をインストールし、ローカルサービスを起動します。

```powershell
python -m pip install -r requirements-web.txt
python -m bookkeeping.web
```

同じ PC のブラウザーで `http://127.0.0.1:8000` を開きます。初回ログインは GitHub 認証を使用し、アプリ専用アカウントの登録は不要です。サービスは初期設定では PC 内からのみアクセスできます。スマートフォンからのアクセスには、LAN と HTTPS の追加設定が必要です。インターネット公開には HTTPS、永続ストレージ、サーバー保護も必要です。詳しくは[Web の公開と同期](docs/WEB_SYNC_SETUP.md)および[GitHub ログイン](docs/GITHUB_WEB_LOGIN.md)をご覧ください。

Web 台帳とデスクトップの SQLite 台帳は初期状態では別々です。Web でデスクトップデータを使うには、Web アプリで明示的に台帳をインポートするか、説明書の手順でバックアップを復元してください。ログインによってデスクトップデータが自動で取り込まれたり上書きされたりすることはありません。スマートフォンでのローカルテストについては[iPhone/PWA テストガイド](docs/IPHONE_PWA_TEST.md)をご覧ください。

## データとプライバシー

- リポジトリには利用者の台帳、口座、予算、API キー、クラウド認証情報、個人設定は含まれません。初回利用時に各自で設定してください。
- デスクトップ台帳はローカルの `data/` に保存されます。Windows の API 接続設定は、現在のユーザーのアプリデータ領域に保存されます。
- リモートモデルを使う場合、リクエストに入力した家計簿の文章、画像、関連するコンテキストがサービス提供者に送信されます。ネットバンキングのパスワードやカード番号全桁は入力しないでください。
- GitHub/Gitee 同期は利用者が接続した場合のみ行われます。同期パッケージには台帳、支払ルール、現在読み込まれている Skill、保存したレシート画像が含まれます。追加の暗号化はされません。[GitHub 同期](docs/GITHUB_SYNC.md)と[Gitee 同期](docs/GITEE_SYNC.md)をご確認ください。
- Web 版の台帳はサービス側のデータディレクトリに保存されます。サーバーデータの保護と HTTPS の設定は運用者の責任です。利用者が操作しない限り、デスクトップデータが Web サービスにアップロードされることはありません。

## CLI と開発

CLI の入口は `python -m bookkeeping.cli` です。例：

```powershell
python -m bookkeeping.cli --help
python -m bookkeeping.cli expense --help
python -m bookkeeping.cli chat
python -m bookkeeping.cli validate
```

`chat` は設定済みのローカル Ollama、または環境変数で指定した OpenAI 互換サービスを使用します。設定方法とデータの扱いは[自然言語 API の説明](docs/NATURAL_LANGUAGE_API.md)をご覧ください。開発者は次のコマンドでテストできます。

```powershell
python -m unittest discover -s tests -v
```
